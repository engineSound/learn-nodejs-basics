# Notes for Claude

This repo is the **bedrock** course for Node.js: keywords, syntax and reserved
words, one at a time ("what does `const` mean?", "where does a program start?").
It is a sibling of `learn-nodejs`, which teaches practical skills on top. Same app,
different lessons. Read these first:

1. `PROGRESS.md`: who the learner is and where they are. Teach from there.
   Its "Learner profile" block is generated by the app; never edit it by hand.
2. `ROADMAP.md`: lesson order.
3. `docs/SHARED-FORMAT.md`: lesson and history formats. **They are shared with
   the other learn-* repos (`learn-nodejs`, `learn-rust` and their `-basics`
   twins); change them in all four or not at all.** So are `docs/tutor/`,
   `docs/fixtures/` and `app/public/` (byte-for-byte).
4. `docs/KEYWORDS.md`: every keyword and reserved word, with the lesson that
   teaches it.

Core requirement (from the learner): **lessons must adapt to the person's
learning, style, progress and reviews.** The app chooses what comes next from
the history (`docs/SHARED-FORMAT.md`, section 5); the in-app tutor writes
extra drills and traces failing code. When adding content, add drills for the
keywords people mix up, not just more core lessons.

Lesson design for the bedrock layer:
- One keyword or symbol family per lesson, about 5–8 minutes.
- *Learn the idea* has a Java contrast table and an ```anatomy block that
  takes a short piece of code apart token by token (format:
  `docs/SHARED-FORMAT.md`, section 1). Every core lesson has one; the tests
  check that each part is found in the code, in order.
- Then a ```run example, two *Quick checks* (```predict; answers are checked by
  running them: write "doesn't compile (E0384)" / "throws TypeError" when the
  point is that it fails), *Your turn*, an *Example*, three graded *Hints* and
  a *Review* tip.
- Exercises are tiny and often start from a compile or runtime error the
  learner fixes, or from an empty file where they write the syntax themselves.

Teaching rules:
- The learner is a professional Java developer. Contrast every keyword with
  its Java equivalent (or say there is none).
- Never hand over a full solution unprompted; give the smallest hint that unblocks.
- Each lesson is a folder `lessons/NN-slug/` with `lesson.md`, `exercise.js`
  (the learner's file) and `exercise.test.js`; lesson 01's checks run
  `node exercise.js` and read its output, lesson 09 ships a read-only
  `units.js`. Tests must pass against a reference solution before committing
  (do not commit the solution).
- `test-fixtures/lessons/` holds sample lessons for the app's own tests; they
  are not part of the course.

App: `app/` (no dependencies; same code as `learn-nodejs`, with its own title,
accent and port 3002). Check with `npm test`, then `npm start` and try a lesson.
